这是一个非常硬核且极具价值的梳理需求。

在当前（特别是 2023-2026 年）的时间序列基础模型（Time Series Foundation Models, TSFMs）和大模型跨界时序的浪潮中，**Loss 函数的选择不仅是一个技术细节，它直接决定了模型是把时间序列看作“物理世界的连续波形”，还是看作“人类语言的离散词汇”。**

我为你将目前主流的时间序列（大）模型进行了详细的阵营划分，主要分为**“距离感知流派（连续回归）”**和**“分类流派（离散 Token 化）”**。

---

### 阵营一：使用“距离 Loss”的模型（连续数值/回归流派）
**核心逻辑**：模型直接在连续的实数空间（$\mathbb{R}$）中进行预测。损失函数（如 MSE、MAE、Huber，或连续概率分布的负对数似然 NLL）**天生具有“距离感知（Distance-aware）”能力**，即错得越远，惩罚越大。

#### 1. 绝对点预测模型（Loss = MSE / MAE）
这些模型直接输出未来的具体数值。
*   **TimesFM (Google)**：预训练和微调全程使用 **MSE（均方误差）**。它将序列切成 Patch，直接通过 MLP 映射为连续值的预测。
*   **PatchTST (经典 Transformer 架构)**：在深度学习时序领域的经典之作，标准的 **MSE/MAE** 损失。
*   **iTransformer / DLinear**：无论是颠覆注意力的 iTransformer 还是极简的 DLinear，底层全都是基于距离的 **MSE** 进行优化。
*   **Time-LLM / GPT4TS**：这是用大语言模型（LLaMA/GPT-2）做时序的代表。它们把大模型最后一层的分类头**砍掉**，换成了线性回归头，强制模型输出连续数值，因此使用的完全是 **MSE/MAE**。

#### 2. 连续概率分布预测模型（Loss = 连续分布 NLL）
这些模型不输出唯一确定的值，而是输出一个数学分布的参数（均值 $\mu$、方差 $\sigma$）。它的 Loss 是连续分布的负对数似然（Negative Log-Likelihood）。因为高斯分布等公式里自带 $(y-\mu)^2$，所以**本质上它依然是高度距离感知的**。
*   **MOIRAI (Salesforce)**：极其庞大的时序基座模型，它假设未来数值服从混合分布（Mixture Distribution），优化目标是连续参数化分布的 **NLL**。
*   **Lag-Llama (Morgan Stanley)**：基于 LLaMA 架构改写的金融时序模型。它预测的是 Student-t 分布的参数，同样使用距离感知的 **Student-t NLL** 进行训练。

---

### 阵营二：使用“分类 Loss”的模型（离散 Token / 语言流派）
**核心逻辑**：模型将连续的数值强行切分成离散的“桶（Bins）”或“词汇（Words）”。既然是词汇，模型就不再关心它们代表的数字有多大差异，而是像做单选题一样，使用**交叉熵（Cross-Entropy, CE）**。这类模型**天生不具备距离感知能力**。

*   **Chronos (Amazon)**：最为典型的代表。它将序列缩放后分入 4096 个独立的桶中（变成 4096 个 Token），直接复用 T5 语言模型的架构，使用标准的 **Categorical Cross-Entropy** 进行训练。
*   **Kronos (Tsinghua)**：我们之前讨论过的用于金融 K 线的模型。利用 BSQ 二元量化生成“宏观 + 微观”的两个子 Token。本质上也是通过语言模型的词表进行预测，使用 **Cross-Entropy**。
*   **LLMTime (Gruver et al.)**：极其粗暴且有效。把时间序列直接当成文本字符串输入（比如数值 `1.23` 变成 Token `'1'`, `'.'`, `'2'`, `'3'`）。完全复用 GPT-3/LLaMA 的预训练逻辑，Loss 就是预测下一个字符的 **Cross-Entropy**。
*   **TimeTok / WaveToken**：将序列或频域特征通过量化器（如 VQ-VAE）变成离散编码表中的索引（Index），后续预测全部使用 **Cross-Entropy**。

---

### 阵营三：前沿探索的“混合/改良”流派
为了弥补上述两大阵营各自的缺点（MSE 难以捕捉多峰概率分布，Cross-Entropy 不懂距离），学术界出现了一批特殊的 Loss 设计：

*   **OCE-TS (Ordinal Cross-Entropy)**：如我们上一个话题讨论的，它是分类流派，但修改了 Loss。它不用标准的交叉熵，而是用**有序交叉熵（OCE）**，强制模型在计算分类惩罚时把“桶的前后顺序和距离”考虑进去。
*   **使用 CRPS（连续排位概率分数）微调的模型**：CRPS 是一种既能评估概率分布，又能衡量绝对距离的指标。一些最前沿的量化微调方案（例如社区对 MOIRAI 或 Chronos 的高级魔改），开始在 Loss 中引入基于 CRPS 或 Wasserstein 距离的惩罚项。

---

### 📊 核心对比总结表

| 维度 | 距离 Loss 阵营 (Continuous/Regression) | 分类 Loss 阵营 (Discrete/Classification) |
| :--- | :--- | :--- |
| **代表模型** | **TimesFM, MOIRAI, Lag-Llama, PatchTST, Time-LLM** | **Chronos, Kronos, LLMTime, WaveToken** |
| **主要 Loss 函数** | MSE, MAE, 连续分布 NLL (高斯/Student-t) | 交叉熵 (Categorical Cross-Entropy) |
| **数据形态** | 浮点数 (Float32 / Float16) | 离散 Token 索引 (整数 Integer ID) |
| **距离感知能力**| **极强**。错得远，惩罚大。 | **极弱/无**。预测 26 和预测 100 都是“错一题”。|
| **概率分布建模**| 只能假设特定的数学分布（如高斯分布，单峰为主）。 | **极强**。无需假设，天然能拟合极其复杂的多峰分布。|
| **适用场景** | 传统时序预测、对点预测精度（MAE/MSE）要求极高的工业场景。 | 金融、极端天气等存在严重随机性和多模态结果的场景；能直接复用现成 LLM 算子。 |

**一句话总结你的调研结果：**
凡是**想直接白嫖现有 NLP 大模型底层算子和框架的（Chronos、LLMTime），几乎都倒向了“分类 Loss”**；而凡是**由时序或传统机器学习团队从头研发的（TimesFM、MOIRAI），都坚守在“距离 Loss”**的阵地。两者现在正在通过诸如你思考的微调策略相互渗透。
